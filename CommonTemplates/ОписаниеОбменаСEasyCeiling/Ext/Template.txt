Обмен данными между 1с Потолки и EasyCeiling или NewMatros происходит посредством текстовых файлов INI.
Для успешного формирования заказа из EasyCeiling или NewMatros в 1с нужно так же перенести справочник фактур с помощью файлов INI

=========================================================================================

Общие требования к файлу INI для загрузки заказа на производство:

1. Кодировка файла INI - Windows-1251 Русский
2. Файл должен содержать две секции: [Заказ] и [Контрагент]
3. Параметры и значения параметров внутри секций разделяются знаком равно (=)
4. Наименования секций и параметров не должны содержать пробелов
5. Наименование файла формируется по правилу [Номер заказа].ini, где [Номер заказа], это номер из заказа EasyCeiling или NewMatros

=========================================================================================

Общие требования к файлу INI для загрузки справочника фактур:

1. Файл выгрузки справочника фактур состоит из одной секции "Материалы"
2. В секции "Материалы" перечисляются все имеющиеся фактуры. 
3. Каждый элемент отображается 4 строчками с параметрами "Цвет[N]","Материал[N]", "Каталог[N]", "ШиринаПолотна[N]", где [N] - порядковый номер элемента при выгрузке

=========================================================================================

Параметры секций с данными о фактурах:
Цвет		//наименование цвета фактуры
Материал	//наименование фактуры
Каталог1	//наименование каталога фактуры, если нет каталогов - пустой
ШиринаПолотна //ширина полотна данного цвета фактуры
