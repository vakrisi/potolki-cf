Расширенные правила обработки файла программы построителя

Параметр файла - наименование числового параметра, чье значение будет использоваться как "Количество" при добавлении записи в ТЧ. Если установлена галка "Правило без параметра", то будет использоваться "Общее значение" из раздела "Вариант определения количества". Галка "Правило без параметра" позволяет определить правило добавление номенклатуры за сам факт загрузки из построителя. Например, в случае упаковки

Номенклатура - номенклатура, которая используется при добавлении записи в ТЧ.

Единица измерения - единица измрения, которая используется при добавлении записи в ТЧ.

Вариант определения количества 

- Из параметра файла - в этом случае при добавлении записи в ТЧ в качестве значения "Количества" будет использоваться значение первого параметра "Параметр файла"

- Общее количество - в этом случае при добавлении записи в ТЧ в качестве значения "Количества" будет использоваться заданное значение 

Коэффициент - значение первого параметра при добавлении в ТЧ будет умножено на заданный коэффициент

Вид заказа - вид заказа, в который будет добавляться запись.

Табличная часть заказа - табличная часть заказа, в которую добавляется запись.

Дополнительные условия срабатывания - поля для задания дополнительного условия: запись добавляется, если значение указанного параметра содержит заданное значение.
