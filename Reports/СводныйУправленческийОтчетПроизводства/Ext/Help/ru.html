Поля:

1. Принято заказов на производство, м² - ЗаказНаПроизводствоДокумент.ПродукцияНоменклатураКоличество

2. Произведено, м² - ЗаказНаПроизводствоДокумент.ПродукцияНоменклатураКоличество в статусе "Подтвержден, ВПроизводстве, Произведен, Отгружен"

3. Коэффициент выработки - (Количество Продуцкии Произведено / Количество Продукции Выработка)-1

4. Выработка, м² - Количество Продукции Выработка

5. Коэффициент затрат пленки (без остатков) - (Количество Пленки / Количество Продукции Произведено) -1

6. Коэффициент затрат пленки (с остатками) - (Количество Пленки + Количество Пленки Остатка / Количество Продукции Произведено)-1

7. Затрачено пленки, м² - Количество Пленки

8. Затрачено остатков, м² - Количество Пленки Остатка

9. Прирост производства, % - ((ПроизведеноВЭтомМесяце / ПроизведеноВПрошломМесяце) * 100) - 100

10. Стоимость потолков, руб. - ЗаказНаПроизводство.ПродукцияСумма

11. Стоимость потолков с услугами, руб. - ЗаказНаПроизводство.ПродукцияСумма + ЗаказНаПроизводство.Услуги.Сумма

12. Стоимость услуг, руб. - ЗаказНаПроизводство.Услуги.Сумма

13. Средняя цена м² потолка, руб. - СтоимостьПотолков / Количество Продуцкии Произведено

14. Средняя цена м² потолка с услугами, руб. - СтоимостьПотолковИУслуг / Количество Продуцкии Произведено

15. Средняя стоимость услуг на каждый м² потолка, руб. - СтоимостьУслуг / Количество Продукции Произведено

 

В зависимости от варианта отчета по дате производства или по дате выпуска продукции в отчет будут выводиться разные данные.
