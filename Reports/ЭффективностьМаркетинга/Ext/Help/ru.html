Расчет данных по колонкам в отчёте.

1. Группа: По дате лида

1.1. Подгруппа: Количественные показатели

- Количество созданных лидов, шт. - сумма всех созданных лидов

- Количество нецелевых лидов, шт. - сумма лидов, которые находятся в статусе "Не целевой", "Сервис" и "Рекламация"

- Количество целевых лидов, шт. - сумма созданных лидов за минусом нецелевых лидов

- Количество назначенных замеров, шт. - сумма лидов, по которым есть хотя бы один назначенный замер

- Количество НЕ закрытых замеров, шт. - сумма лидов, по которым нет результата последнего замера (пустой результат замера)

- Количество закрытых замеров, шт. - сумма лидов, по которым есть результат последнего замера (Договор не заключен, Заключен договор, Замер не выполнен, Замер отменен)

- Количество выполненных замеров, шт. - сумма лидов, по которым последний замер выполнен

- Количество НЕ выполненных замеров, шт. - сумма лидов, по которым результат последнего замера

- Количество оформленных договоров, шт. - сумма оформленных договоров (во всех статусах кроме расторгнут) по лидам

1.2. Подгруппа: Конверсия воронки продаж (расчет по данной подгруппе выполняется на основе данных из подгруппы в п 1.1. "Количественные показатели")

- Целевые лиды от созданных лидов

- Конверсия (назначенные замеры / целевые лиды), %

- Выполненные замеры от назначенных, %

- Конверсия (договоры / выполненные замеры), %

1.3. Подгруппа: Конверсия по выполненным замерам (расчет по данной подгруппе выполняется на основе данных из подгруппы в п 1.1. "Количественные показатели")

- Выполненные замеры от назначенных, %

- Конверсия (выполненные замеры / целевые лиды), %

1.4. Подгруппа: Конверсия по договорам (расчет по данной подгруппе выполняется на основе данных из подгруппы в п 1.1. "Количественные показатели")

- Конверсия (договоры / целевые лиды), %

- Конверсия (договоры / назначенные замеры), %

- Конверсия (договоры / выполненные замеры), %

Показатели ниже рассчитываются по договорам, по которым дата лида (основания договора) и договора попадает в выбранный период отчёта

- Сумма договоров

- Общая площадь потолков, м2 - сумма количества номенклатуры с видом "Потолок", "Отрез" или "Типовой отрез" в договоре

- Средняя площадь потолков, м2 - общая площадь потолков деленная на количество оформленных договоров

- Средняя стоимость 1 м2 - - сумма договоров деленная на общую площадь потолков

- Средняя стоимость договора - сумма договоров на количество оформленных договоров

- Средний чек - рассчитывается если включена настройка "Вся номенклатура по умолчанию в среднем чеке", расчет производится по номенклатуре, у которой снят флаг "Не учитывается в среднем чеке"

2. Группа: Оформлено договоров за период (Показатели ниже рассчитываются по договорам, по которым дата договора попадает в выбранный период отчёта)

- Сумма договоров

- Общая площадь потолков, м2 - сумма количества номенклатуры с видом "Потолок", "Отрез" или "Типовой отрез" в договоре

- Средняя площадь потолков, м2 - общая площадь потолков деленная на количество оформленных договоров

- Средняя стоимость 1 м2 - сумма договоров деленная на общую площадь потолков

- Средняя стоимость договора - сумма договоров на количество оформленных договоров

- Средний чек - рассчитывается если включена настройка "Вся номенклатура по умолчанию в среднем чеке", расчет производится по номенклатуре, у которой снят флаг "Не учитывается в среднем чеке"

3. Группа: Выполнено монтажей (Показатели ниже рассчитываются по монтажам, по которым дата документа монтаж попадает в выбранный период отчёта)

- Сумма выполненных монтажей - сумма монтажей, которые находятся в статусе "Выполнен" или "Закрыт".
