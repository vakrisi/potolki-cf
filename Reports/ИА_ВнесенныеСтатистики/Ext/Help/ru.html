Отчет по внесенным статистикам

Отчёт предназначен для отображения информации по статусу ввода статистик в рамках каждого поста всех оргсхем компании. Цветом выделяются результаты, в соответствии с способом заполнения статистики, Статистики, заполняемые запросом или конструктором будут выделены жёлтым цветом.

При открытии отчёта можно указать ряд фильтров и настроек:

  • Период – Выбрать данные за определённый период

  • Пост – Выбрать данные по конкретному посту

  • Вид статистики – Определить конкретную статистику, которая вас интересует

  • Аналитика 1-3 – Отбор по значению детализации при вводе данных статистики

  • Данные внесены – Отображение только внесённых статистик или только не внесённых

Дата заполнения – отбор данных по конкретной дате заполнения.
