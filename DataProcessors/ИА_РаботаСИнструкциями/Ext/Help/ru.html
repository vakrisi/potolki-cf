«Работа с инструкциями»

«Работа с инструкциями» предоставляет возможности просмотра должностных инструкций за период, отбора по условиям, поиска по тегам.

Для отбора должностных инструкций по дате создания необходимо установить период «Дата выпуска» и нажать кнопку «Обновить».

Реализован отбор инструкций по посту, типу, серии и статусу,а также поиск по тегам.

Чтобы просмотреть текст должностной инструкции, необходимо два раза щелкнуть по инструкции. Текст инструкции отобразится в нижней левом окне рабочего стола. Если в тексте должностной инструкции встречается слово или склонение слова из глоссария, оно отображается подчеркнутым. Для просмотра определения необходимо щелкнуть по слову.

В правом нижнем окне рабочего стола отображается история просмотра инструкций. Для перехода по истории просмотра служат кнопки «Назад» и «Вперед».

Для печати должностных инструкций служит кнопка «Печать».

Для удобства работы с должностными инструкциями можно включать/отключить разделы Отбор, Список, История. Для этого служат кнопки в верхней части окна.
