«Рабочий стол Комплексной Системы Управления»

Подробнее о создании задач, посланий и ЗРС.

Коммцентр

Задачи и послания пользователя разделены по группа (категориям):

  • Входящие — содержит задачи (послания), не рассмотренные пользователем. Задача поставлена пользователю (послание отправлено), но еще не обработана им.

  • В работе — содержит задачи с установленным статусом «В работе».

  • Исходящие — содержит невыполненные (не прочитанные) задачи (послания), поставленные текущим пользователем другим пользователям или себе.

  • Архив— содержит выполненные задачи и прочитанные послания, автором которых является текущий пользователь.

  • Все — содержит задачи и послания всех пользователей информационной базы.

Чтобы поставить задачу пользователю/посту необходимо нажать на кнопку «Создать задачу».

Чтобы отправить послание пользователю/посту необходимо нажать на кнопку «Создать послание».

Чтобы отправить ЗРС пользователю/посту необходимо нажать на кнопку «Создать ЗРС».

Статистики

Рабочий стол КСУ отображает диаграмму по настройке статистики, указанной на вкладке "Статистики" поста пользователя.

Настройками над полем вывода диаграмм можно управлять периодом и детализацией построения диаграмм статистик.

Чтобы построить статистики после изменения настроек необходимо правой кнопкой мыши нажать по диаграмме и выбрать пункт "Обновить".

Чтобы ввести значение статистики необходимо правой кнопкой мыши нажать по диаграмме и выбрать пункт "Добавить значение".

Планы действий

Рабочий стол КСУ отображает боевые планы поста пользователя, а также боевые планы постов, подчиненных посту пользователя при установленной настройке КСУ "Показывать планы подчиненных".

Для создания боевого плана необходимо в левом окне нажать правой кнопкой мыши и выбрать пункт «Добавить». Для создания боевого плана на основании ранее созданного необходимо нажать по соответствующему плану правой кнопкой мыши и нажать «Создать копированием».

При активизации плана в правом окне отобразится план действий. При двойном щелчке по плану открывается форма боевого плана.

После выполнения запланированного действия плана, в колонке «Выполнено» устанавливается галочка.

Для обновления списка планов служит пункт «Обновить»
