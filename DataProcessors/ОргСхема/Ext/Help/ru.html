«Оргсхема»

«Оргсхема» позволяет:
  • просматривать графический вид оргсхемы;
  • редактировать оргсхему, создавать подчиненные терминалы;
  • отправлять послания, создавать задачи;

  • просматривать статистики терминала, планы действий, должностные инструкции.

Просмотр и редактирование оргсхемы

Чтобы просмотреть оргсхему необходимо выбрать организацию из справочника "Организации".

Чтобы перейти к редактированию терминала оргсхемы необходимо дважды щелкнуть левой кнопкой мыши по терминалу, в открывшейся форме элемента справочника «Оргсхема» внести необходимые изменения и записать элемент. Для того, чтобы изменения отобразились на оргсхеме служит кнопка «Обновить».

Чтобы создать подчиненный терминал необходимо правой кнопкой мыши нажать на вышестоящий пост и из контекстного меню выбрать пункт «Добавить подчиненного». В открывшейся форме создания починенного терминала автоматически заполненятся поля «Вышестоящий пост» и «Тип терминала». Тип подчиненного терминала устанавливается в зависимости от типа вышестоящего поста. Например, при создании подчиненного терминала для терминала с типом «Департамент», установится тип терминала - «Отдел».

Постановка задач, отправка посланий и ЗРС на пост

Чтобы отправить послание посту, необходимо нажать правой кнопкой мыши по терминалу и в появившемся контекстном меню выбрать пункт «Задачи - Отправить послание». Если в адресации задач коммцентра указано несколько пользователей одного терминала, то после выбора пункта «Отправить послание» на экране появится список пользователей для выбора.

Чтобы поставить задачу на пост, необходимо нажать правой кнопкой мыши по терминалу и в появившемся контекстном меню выбрать пункт «Задачи - Поставить задачу». После создания задачи на орхсхеме будет выделена коммуникационная линия по задаче. В форме задачи появится вкладка «Коммлинии».

Чтобы отправить ЗРС посту, необходимо нажать правой кнопкой мыши по терминалу и в появившемся контекстном меню выбрать пункт «Задачи - Отправить ЗРС».

Чтобы просмотреть текущие задачи поста необходимо нажать правой кнопкой мыши по терминалу и в появившемся контекстном меню выбрать пункт «Задачи - Текущие задачи». Чтобы в открывшейся форме просмотреть задачу необходимо два раза щелкнуть по строке с описанием задачи.

Просмотр статистик терминала

Чтобы просмотреть график статистики терминала необходимо нажать правой кнопкой мыши по терминалу и в появившемся контекстном меню выбрать пункт «Показать статистики». В результате откроется рабочий стол статистик с настройкой, заданной для терминала, и графиком статистики, построенным по настройке за текущую неделю.

Просмотр планов и должностных инструкций

Чтобы просмотреть планы действий необходимо нажать правой кнопкой мыши по терминалу и в появившемся контекстном меню выбрать пункт «Планы».

Чтобы просмотреть должностные инструкции терминала необходимо нажать правой кнопкой мыши по терминалу и в появившемся контекстном меню выбрать пункт «Должностные инструкции».

Работа с архивом

Чтобы сохранить версию оргсхемы необходимо воспользоваться пунктом Архив — Поместить в архив, ввести наименование версии (по умолчанию, наименование организации) и нажать «ОК».

Чтобы открыть сохраненную версию оргсхемы необходимо воспользоваться пунктом Архив — Получить из архива, в открывшейся форме со списком версий оргсхемы выбрать версию и нажать «ОК».
