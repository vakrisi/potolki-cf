«Информационный центр организации» (ИЦО)

"ИЦО" предоставляет возможность построения главных статистик постов оргсхемы организации.

Настройка статистики для поста указывается на вкладке «Статистика» соответствующего элемента справочника «Оргсхема». . В настройке статистики должен быть установлен флаг «Показывать в ИЦО». На оргсхеме краткое наименование для РС и ИЦО должно быть заполнено короткое название департаментов, отделов для оптимального отображения ИЦО.

В поле «Организация» выбирается организация, для постов которой будут строиться статистики.

Далее указываются данные о периоде построения. Существуют следующие варианты указания периода:

  • ввести количество периодов и тип периода построения. Период построение автоматически рассчитается на основе указанных данных.
  • указать период построения в ручную
 

При помощи полосы регулирования «Масштаб» задается количество диаграмм в строке.

Для построения статистик служит кнопка «Построить статистики».

Для просмотра построенного графика статистики на рабочем столе статистик необходимо нажать правой кнопкой мыши по графику статистики и выбрать пункт «Открыть». Для просмотра расшифровки построенного графика статистики необходимо нажать правой кнопкой мыши по графику статистики и выбрать пункт «Вывести расшифровку». Для ввода значений статистики необходимо правой кнопкой мыши щелкнуть по графику и выбрать пункт «Добавить значение».
