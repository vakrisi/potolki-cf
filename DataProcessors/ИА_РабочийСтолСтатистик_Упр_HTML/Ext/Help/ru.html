«Рабочий стол статистик»

«Рабочий стол статистик» предназначен для построения статистик за указанный период.

В поле "Настройка" выбирается настройка рабочего стола статистик из справочника "Настройки рабочего стола статистик".

Период построения статистик заполняется автоматически в соответствии со значениями "Период" и "Количество периодов построения" из выбранной настройки. Поле «Количество графиков в строке» заполняется из выбранной настройки. Кнопками «Вверх/вниз» или ручным вводом значения можно изменять количество диаграмм в строке.

Основная форма содержит три страницы:

  • Рабочий стол статистик
  • Настройка рабочего стола статистик 
  • Расшифровка

Страница "Рабочий стол статистик" отображает построенные диаграммы статистик.

Страница «Настройка рабочего стола статистик» содержит таблицу, идентичную таблице выбранной настройки рабочего стола статистик. На странице можно изменить настройки построения диаграмм статистик.

Страница «Расшифровка» отображает отчет-расшифровку диаграммы статистики. В отчет-расшифровку выводятся поля, которые указаны в виде статистики на вкладке «Расшифровка» в таблице «Поля расшифровки». Чтобы просмотреть расшифровку, необходимо правой кнопкой мыши щелкнуть по диаграмме статистики и выбрать пункт «Вывести расшифровку». Отчет-расшифровка диаграммы с несколькими графиками статистик выводится по каждому графику отдельно.

Для построения статистик после изменения настроек, например, изменения периода, служит кнопка «Обновить».

Для печати графиков статистик служит кнопка «Печать». Печать статистик будет происходить в соответствии с настройкой КСУ «Ориентация листов при печати статистик».

Чтобы ввести значение статистики, необходимо правой кнопкой мыши щелкнуть по диаграмме статистики и выбрать пункт «Добавить значение». Для ввода значения статистики из диаграммы с несколькими графиками статистик, необходимо сначала выбрать аналитику, для которой вводится значение.
