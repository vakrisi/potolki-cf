«Работа с глоссарием»

«Работа с глоссарием» предоставляет возможности просмотра слов, отбора по постам, возможности работы со списками слов.

Поле «Слово» предназначено для отбора слов по введенным буквам. Необходимо ввести слово или его часть и нажать Enter.

Для отбора слов по постам служит поле «Пост». Слова, соответствующие отбору, выводятся в поле «Глоссарий». В поле «Определение» отображается определение текущего слова.

Поля «Текущий список слов для печати» и «Сохраненные списки для печати» предназначены для работы со списками слов глоссария. Существуют следующие способы создания списков слов:

  • используя поле «Текущий список слов для печати». Чтобы добавить слово в список необходимо нажать на кнопку «Добавить» на панели инструментов поля и выбрать слово из справочника «Определения». Чтобы добавить текущее слово из поля «Глоссарий» необходимо выделить слово и нажать кнопку «Добавить слово» или дважды щелкнем по слову. Чтобы сохранить созданный список необходимо нажать на кнопку «Сохранить в новый список», в появившейся форме ввести наименование списка и нажать «ОК».

  • используя поле «Сохраненные списки для печати». Для создания списка необходимо нажать кнопку «Создать», в открывшейся форме ввести наименование списка и заполнить табличную часть словами. Чтобы отредактировать список слов, необходимо выделить список в поле «Сохраненные  списки для печати» и нажать кнопку «Загрузить из текущего списка». Список слов будет перезаполнен содержимым текущего списка. Для перезаписи текущего списка служит кнопка «Сохранить в текущий список».

В «Сораненный список слов для печати» можно добавить слова из существующего списка для печати. Для это необходимо выделить список и нажать кнопку «Добавить из текущего списка слов для печати».

Чтобы вывести список на печать служит кнопка «Печать списка».
