Документ «Ввод значения статистик»

Документ «Ввод значения статистик» предназначен для ручного ввода значений статистик.

Реквизиты шапки документа:

  • Дата. Дата ввода значения статистики.
  • Вид статистики. Вид статистики из справочника "Виды статистик", для которой вводится значение.
  • Аналитика 1, Аналитика 2, Аналитика 3. Значения аналитик. Типы значений аналитик определяются из выбранного вида статистики.
  • Количество. Значение статистики.
