Протокол рекомендательного совета


    1. Для доступа к справочнику протоколов служит пункт меню Планы действий – Протокол Рекомендательного Совета.

      Чтобы создать новый протокол необходимо нажать на кнопку «Создать» на панели инструментов формы справочника «Протоколы рекомендательного совета».

      Председатель РС заполняется автоматически по данным настройки блока в параметрах КСУ. Так же в настройках можно указать параметры, при которых протокол РС будет сформирован в детализации статистик или планов по отделам, а не по отделениям.


      Далее, в протоколе РС в обязательном порядке указывается следующая информация:

      Участники совета – перечень постов, которые присутствуют на собрании РС. Названия для этих постов берутся из данных оргсхемы (поле краткое наименование для протокола РС)

      Статистика поста РС, её значение и состояние – Указывается основная статистика РС, её значение и состояние статистики. При необходимости вы можете просмотреть график статистики по кнопке «Показать статистику».

      Обзор и оценка положения дел - Просмотрите весь ИЦО по кнопке «ИЦО Организации» и внесите краткое резюме в одноимённое поле.

      Доклад по статистикам и квотам. Регистрируются значения главных статистик членов рекомендательного совета – Данные статистики автоматически приходят из боевых планов постов, если они были заполнены своевременно. Вам же необходимо внести данные о том, «Что было сделано» в соответствующее поле таблицы

      Выполненные и запланированные к выполнению задачи по стратегическим и тактическим планам. В данных таблицах, в свободном формате вписываются выполненные и запланированные к выполнению задачи по каждому отделению или ответственному. Для добавления новых  строк используйте кнопку .

      Рассматриваются боевые планы отделений или отделов – Боевые планы автоматически приходят по каждому посту, если они были заполнены своевременно. При необходимости вы можете переключиться на закладку «Прошлая неделя», чтобы просмотреть планы прошлой недели.

      • Вносится информация по решённым за прошлую неделю проблемах.

      • Вносится информация по разработанной или предложенной оргполитике

      • Вносится информация о поощрениях и наказаниях – указывается кого на этой неделе следует поощрить или наказать и каким образом

      • Вносится информация о переводах и назначениях – Вписывается информация по изменения в организующей схеме

      • Заполняется ссылка на документ финансового планирования

      Далее протокол РС записывается и закрывается при помощи кнопки «Записать и закрыть». После чего, исполнительный совет открывает данный документ и вносит информацию по данному протоколу, одобряя его или не одобряя. При необходимости вносится информация по коррекции.

      Печатную форму протокола можно получить при помощи кнопки «Печать»
