«ЗРС»

    ЗРС состоит из вкладок: «Задача», «Файлы». 

 Вкладка «Задача»  

  • Наименование. Краткое содержание задачи.

  • Дата. Дата создания задачи, автоматически текущей датой.
  • Срок исполнения. Дата выполнения задачи
  • Автор. Заполняется автоматически текущим пользователем после записи послания.
  • Напоминать с ... по... . Определяет промежуток времени, в течение которого пользователь будет получать уведомление о задаче. (Рис. 1).

 

Рис.1 Установка периода напоминания о новой задаче

  • Ситуация. Заполняется подробным описанием ситуации.

  • Данные. Заполняется подробным описанием данных.
  • Решение. Заполняется подробным описанием решения (Рис. 2).

 

Рис.2 Описание ЗРС

 

  • Объект. Объект информационной базы, которым может являтся любой документ или элемент справочника в системе 1С.
  • Пользователь. Указывается пользователь из справочника "Пользователи", для которого ставится задача (Рис. 3).

    Рис.3 Указание пользователя в задаче.

    •

            Чтобы поставить задачу списку пользователей необходимо нажать на кнопку "Список пользователей" рядом с полем «Пользователь» , в открывшемся списке указать пользователей задачи и нажать "Готово" (Рис. 4).

    Рис.4 Указание списка пользователей в задаче.

             Если задача создаётся для группы пользователей, то она отправляется каждому пользователю, как отдельная задача, которую нужно выполнить каждому сотруднику в списке исполнителей по отдельности.

  • Пост. Выбирается пост организации из справоника "Оргсхема", на который ставится задача (Рис. 5).

     Рис.5 Создание задачи на пост организации.

      В соответствии с «Адресацией задач коммцентра» поставленная задача отображается у пользователей поста (Рис. 6).

     Рис.6 Адресация задач коммцентра.

  • Дата выполнения. Заполняется автоматически текущей датой при установке статуса «Выполнена».
  • Ход выполнения. Этапы работы с задачей
     
     Чтобы добавить пункт работы по задаче вручную необходимо нажать на кнопку «Добавить комментарий», в открывшемся окне ввести пояснения и нажать «Ок».
     

    Вкладка «Файлы»

    Вкладка содержит файлы по задаче, можно добавлять, открывать, сохранять файлы по задаче .
