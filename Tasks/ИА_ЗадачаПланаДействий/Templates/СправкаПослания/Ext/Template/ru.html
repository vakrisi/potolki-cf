«Послания»

 Создать послание - Послания используются для информационного обмена сообщениями между сотрудниками организации. Используйте послания для уведомления коллег.

  • Наименование. Краткое содержание послания.

  • Дата.    Дата создания послания, автоматически текущей датой.
  • Автор. Заполняется автоматически текущим пользователем после записи послания.
  • Напоминать с ... по... . Период напоминания о новом послании (Рис. 1). Если в настройках КСУ в поле Период напоминания о новых задачах значение больше 0, тогда все новые послания будут появляться в виде напоминания каждый N (введенное значение) секунд в периоде.

       

Рис. 1 Установка периода в новом послании.

  • Содержание.    Подробное описание послания.
  • Пользователь. Указывается пользователь из справочника "Пользователи", которому отправляется послание. Чтобы отправить послание списку пользователей необходимо нажать на кнопку рядом с полем «Пользователь», в открывшемся списке указать пользователей и нажать "Готово".
  • Пост. Выбирается пост организации из справоника "Оргсхема".

Для того, чтобы отметить послание как прочитанное, необходимо нажать на кнопку «Прочитано» (Рис. 2).
