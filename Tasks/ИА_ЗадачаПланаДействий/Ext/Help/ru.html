«Задача плана действий»

Создать задачу - Данный вариант используется , когда необходимо получить конкретный результат деятельности от какого-либо сотрудника организации. Чаще всего задания пишутся руководителями предприятий для своих подчинённых.

Создать послание

- Послания используются для информационного обмена сообщениями между сотрудниками организации. Используйте послания для уведомления коллег.

Создать ЗРС

- Законченная работа сотрудника, чаще всего пишется подчинёнными для своих руководителей или руководителей смежных подразделений. Документ описывает как можно достичь результат силами других подразделений.

Чтобы поставить задачу пользователю необходимо нажать на кнопку «Создать» - задачу».

Форма задачи состоит из полей

«Тема» указывается краткое содержание задачи.

«Содержание задачи» указывается полное содержание задачи.

«Срок» указывается желаемая дата выполнения задачи.

«Сотруднику» заполняется исполнителем задачи и его постом, можно выбрать из занимаемых пользователем постов, пост можно сменить для корректировки командной линии.

Гиперссылка «Прикрепить элемент справочника, документ» использована специально для того, чтобы прикрепить к задаче объект информационной системы, которым может являться любой документ, элемент справочника, задача или бизнес-процесс в системе 1С. Для того, чтобы убрать ссылку из задачи нажмите на кнопку «Очистить».

При отправке задачи на пост появляется 2 различных способа доставить задачу целевому посту.

Сохранить и отправить – отправит задачу посту по коммуникационной линии, и он получит её сразу.

Отправить по командным линиям – Отправит задачу по командным линиям организующей схемы и она пройдёт процедуру согласования прежде, чем попасть с целевому посту.


В соответствии с «Адресацией задач коммцентра» поставленная задача отображается у пользователей поста


Лента событий

В ленте отображаются все события, которые происходили с задачей. Чтобы добавить пункт работы по задаче вручную необходимо нажать на кнопку «+ комментарий», в новой строке внести пояснения и закрыть задачу.

В системе можно прикреплять файлы по задаче, открывать и сохранять файлы из при помощи ссылки «Прикреплённые файлы».

В случае, если работа по созданию задачи не завершена и требуется её отложить на неопределённый срок, можно нажать на кнопку «Записать как черновик». Задача попадёт во вкладку «Исходящие» но не будет отправлена получателю, при этом, в общем списке задача будет выделена серым цветом.

Работа с задачами

После отправки задачи пользователю, она отображается у него в комцентре в группе «Входящие». Полученная задача имеет панель  инструментов. Которая содержит некоторые функции:

  • Если вы добавили комментарий, но не хотите завершать задачу, просто нажмите «Записать и закрыть».

  • если задача поставлена пользователю, нажать кнопку в папку «В работе»

  • если задача попала вам не по адресу или она некорректная, нажать кнопку «Отказаться»

  • если задача попала вам не по адресу и её требуется перенаправить другому сотруднику, нажать кнопку «Передать другому сотруднику»

  • если задача поставлена посту, нажать кнопку «Взять задачу себе»

  • Чтобы отметить выполнение задачи необходимо заполнить поле «Доклад об исполнении» нажать кнопку «Выполнено»

После выполнения задачи пользователем, она передаётся на проверку автору. Автор имеет возможность вернуть задачу исполнителю на доработку, для этого можно добавить комментарий и нажать кнопку «Вернуть на доработку», в результате у исполнителя в комцентре снова появится задача в группе «Входящие». Если задача выполнена корректно, нажимается кнопка «Принять».

По кнопке «Печать» можно сформировать печатную форму задачи.

Просроченные задачи (срок исполнения уже прошёл) обозначаются темно-розовым цветом.

 

Послания

Чтобы создать послание пользователю необходимо нажать на кнопку «Создать» -  «Послание».

Форма послание представлена ниже

Поля «От» послания заполняется автоматически при записи послания.

В поле «Тема» указывается краткое содержание послания.

Поле «Содержание» заполняется подробным описанием послания.

В поле «Сотруднику» указывается пользователь или пост, для которого создается послание


Для того, чтобы отметить послание как прочитанное, необходимо нажать на кнопку «Прочитать и отправить в архив» или «Прочитать и ответить».

К посланиям, так же, как и к задачам можно прикреплять различные объекты и файлы, для этого служат гиперссылки внизу формы. Доступна печатная форма.

ЗРС

  1. Чтобы поставить ЗРС пользователю необходимо нажать на кнопку «Создать ЗРС».

  3. На форме указывается основная информация о ЗРС:

  • «Тема» указывается краткое содержание ЗРС.

  • «От» заполняется автоматически текущим пользователем и его постом после записи ЗРС, пост можно сменить для корректировки командной линии.

  • «Сотруднику» заполняется исполнителем ЗРС и его постом, можно выбрать из занимаемых пользователем постов, пост можно сменить для корректировки командной линии

  • «Ситуация» заполняется подробным описанием ситуации

  • «Данные» заполняется подробным описанием данных

  • «Решение» заполняется подробным описанием решения

Все остальные функции отправки, печати, ленты событий абсолютно аналогичны задаче.

 Создать на основании ЗРС или задачи дополнительную задачу или ЗРС

Чтобы создать на основании ЗРС или Задачи дополнительную ЗРС или Задачу необходимо нажать кнопку «Создать на основании» в открытой Задаче или ЗРС, откроется меню с выбором вида того или иного послания, которое вы можете создать на основании уже имеющегося (например, на основании ЗРС одобренной руководителем).

При создании на основании, необходимо будет заполнить те же поля, что и в обычном документе(см. выше Задачи, Послания, ЗРС). В новом созданном документе, будет указана ссылка на тот документ, на основании которого он был сформирован. Получатель частицы, сможет в любой момент, перейдя по ссылке, открыть исходный документ.
