У меня одна организация


В этом случае откройте строку «Инструкция для всех организаций, кроме описанных отдельно». Ознакомьтесь с текстом в этой инструкции и замените весь текст на свой. При создании заказов будет показан измененный вами текст.


У меня несколько организаций


В этом случае откройте строку «Инструкция для всех организаций, кроме описанных отдельно». Ознакомьтесь с текстом в этой инструкции, чтобы понять, как создавать свои инструкции. Затем создайте отдельные инструкции под каждую организацию. 


Почему? Структуры фондов и статей расходов могут отличаться у разных организаций. Для того, чтобы не вводить сотрудников в замешательство, лучше создать точное описание с упоминанием фондов и статей расходов именно для конкретной организации. Тогда при создании заказа на приобретение от имени конкретной организации сотрудник увидит точную инструкцию.


Чтобы создать отдельную инструкцию кликните кнопку «Создать», выберите из списка организацию и добавьте текст инструкции. Обратите внимание, что при выборе организации будут показаны только названия организаций, которые считаются головными.


Что будет, если при создании заказа выбирают дочернюю организацию


Представьте, что есть головная организация ООО «Голова» и дочерняя ООО «Дочка». И вы создали инструкцию для головной организации. При создании заказа сотрудник указал, что заказ должен быть выплачен от имени ООО «Дочка». Система определит, что у ООО «Дочка» есть головная организация и покажет инструкцию, созданную вами для ООО «Голова».


Что будет, если инструкцию пометить на удаление


Для любой головной организации может быть только одна активная инструкция. Поэтому вариантов развития событий может быть два: 


(1) Если для организации «А» есть инструкция, отмеченная на удаление, и в списке есть другая строка с активной инструкцией для той же организации «А», то при создании заказа на приобретение от имени организации «А», то будет показана действующая инструкция для «А».


(2) Если для организации «А» есть инструкция, отмеченная на удаление, и в списке нет другой строки для этой же организации, то при создании заказа будет показана «Инструкция для всех организаций, кроме описанных отдельно».
