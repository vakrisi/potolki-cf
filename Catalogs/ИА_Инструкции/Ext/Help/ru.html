Справочник «Инструкции»

Справочник «Инструкции» предназначен для хранения информации о должностных инструкциях организации.

Закладка «Представление»

На закладке отображается текст должностной инструкции, недоступна для редактирования.

Закладка «Основные данные»

  • Наименование. Наименование должностной инструкции.
  • Дата создания. Заполняется автоматически текущей датой, но доступна для редактирования.
  • Дата обновления. Изменяется при записи должностной инструкции в статусе «Действует»
  • Версия. Версия докумениа - обозначение (R0) – версия должностной инструкции.
  • Тип инструкции. Выбирается тип инструкции из справочника "Типы инструкций".
  • Статус. Выбирается одно из предопределенных значений: проект, на согласовании, действует.

  • Подписант. Выбирается сотрудник из справочника "Сотрудники", подпись которого будет выводиться в печатной форме должностной инструкции.

В табличной части «Посты» указываются посты организации из справочника "Оргсхема", к которым относится должностная инструкция. Если для выбранного поста установлен признак «Всем сотрудникам», то инструкция будет доступна всем постам, подчиненных выбранному.

В табличной части «Серии» указываются серии инструкции.

Закладка «Ознакомление»

По нажатию кнопки "создать задачу на ознакомление" автоматически посылает документ на ознакомление комцентр сотрудников, указанных в списке.

Работа с шаблонами

При создании текста должностной инструкции можно использовать шаблоны. Например, создать шаблоны заголовка, подписей, блоков, часто используемых в текстах инструкций, а затем добавляем шаблон в текст. Данная возможность значительно ускоряет составление должностных инструкций.

Для создания шаблона необходимо ввести текст шаблона и перейдем в меню Шаблоны - Сохранить как новый шаблон. В открывшемся окне ввести наименование шаблона и нажать «ОК».

Для вставки шаблона в текст должностной инструкции необходимо установить курсор строке и перейдем в меню Шаблоны – Добавить из шаблона и в открывшейся форме выбрать шаблон.

Наряду с командой «Добавить из шаблона» реализована возможность загрузки из шаблона. Для этого служит команда меню Шаблоны – Загрузить из шаблона. Отличие заключается в том, что при загрузке из шаблона заменяется весь текст должностной инструкции на текст из шаблона. После выбора шаблона на экране будет выведен диалог для подтверждения действия.

Можно перезаписать существующий шаблон содержимым инструкции. Для этого служит команда меню Шаблоны - Записать в существующий шаблон. После выбора шаблона, содержимое которого будет перезаписано, на экране будет выведен диалог для подтверждения действия.

Работа с ссылками

Чтобы вставить в текст инструкции переменную инструкции необходимо перейти в меню Группа гиперссылки - Добавить переменную.

Чтобы вставить в текст инструкции ссылку на другую должностную инструкцию необходимо перейти в меню Группа гиперссылки - Добавить ссылку на инструкцию.

Реализована возможность загрузки должностной инструкции из документа

Microsoft Word. Для этого служит кнопка «Загрузить из Word».

Для печати должностной инструкции служит кнопка «Печать». В процессе вывода должностной инструкции на печать будет задан вопрос о необходимости печати подписи.
