Справочник «Оргсхема»

Справочник «Оргсхема» предназначен для хранения информации о структуре организации.

Существует два способа создания структуры организации:

  • автоматически. Для этого необходимо нажать на кнопку «Создать стандартную» и в открывшейся форме ввести наименование организации. В результате будет автоматически создана структура организации.
  • вручную.

Закладка «Основная информация»

  • Вышестоящий пост. Терминал организационной структуры, которому подчинен текущий терминал.
  • Тип терминала. Выбирается тип терминала: организация, учредитель, руководящий состав, департамент, отдел, секция, сотрудник. Тип терминала определяет положение элемента на оргсхеме.
  • Имя терминала. Наименование терминала.
  • Краткое наименования для протокола РС и ИЦО. Краткое название терминала для отображения в протоколе рекомендательного совета и информационного центра организации.
  • Сотрудники. Указываются руководители терминала из справочника "Физические лица".
  • Обязанности. Описание обязанностей сотрудников терминала.
  • ЦКП. Ценный конечный продукт терминала.

Закладка «Оформление»

  • Цвет фона. Цвет фона терминала на орхсхеме.
  • Шрифт. Шрифт надписей в терминале.
  • Высота. Высота терминала.
  • Ширина. Ширина терминала.
  • Высота заголовка. Высота текстового блока с наименованием для типа терминала «Секция».
  • Сортировка. Положение терминала по горизонтали относительно терминалов такого же уровня подчинения.
  • Поднять вверх. При установленном флаге, терминал с типом «Департамент» сдвигается вертикально вверх.

  • Фотографии. Вывод фотографии сотрудников терминала (должна быть установлена настройка «Печать фотографий сотрудников» в настройках КСУ). Фотография назначается в элементе справочника «Физические лица»

По кнопке "Применить оформление" настроенное оформление терминала оргсхемы можно применить к другим терминалам того же уровня. В открывшейся форме необходимо указать переносимые настройки и терминал, в пределах подчинения которого будет переноситься оформление.

    Закладка «Статистики»

    На закладке выбирается настройка рабочего стола статистик, по которой будет автоматически строиться статистика терминала.

    Уведомлять о заполнении статистик. Настройка уведомлений о заполнении статистик подчиненными с указанием уровня подчиненности.
