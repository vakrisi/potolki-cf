Справочник «Виды статистик»

Справочник «Виды статистик» предназначен для хранения информации о видах статистик.

Закладка «Основная информация»

  • Наименование. Наименование вида статистики.
  • Аналитика 1, Аналитика 2, Аналитика 3. Аналитики из справочника "Виды аналитики статистики", в разрезе которых будет вестись статистика. 
  • Вид итогов. Выбирается вид итогов статистики: сумма или среднее значение. Итоги отображаются в заголовке диаграммы статистики.
  • Обратная (Перевернутая) статистика. Если признак установлен, то график статистики отображается зеркально по вертикали.
  • Статистика показывает текущее состояние. Если признак не установлен, то значения статистики в праздничные/выходные дни перераспределяются на рабочие, если признак установлен — перераспределения не происходит.
  • Ширина линии на графике– определяет толщину линии при отображении на всех графиках.

Закладка «Источник данных»

  • Вариант получения данных. Выбирается вариант получаения данных для статистики: документом статистика или из запроса.  Если выбран вариант "Документ статистика", значения статистики вводятся документом "Ввод значения статистик". Если выбран вариант "Из запроса", в поле "Текст запроса" необходимо создать запрос, который будет получать данные из базы данных. На основе этих данных будет строиться график статистики.
  • Проверить статистику. Выводятся данные в табличном виде для проверки статистики. 

  • Период проверки статистики. Выбирается период за, который необходимо вывести статистику для проверки.

  • Проверочный список. Список подпродуктов, составляющих статистику.
