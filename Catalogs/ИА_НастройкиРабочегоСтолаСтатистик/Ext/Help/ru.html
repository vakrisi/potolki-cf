Справочник «Настройки рабочего стола статистик»

Справочник «Настройки рабочего стола статистик» предназначен для хранения настроек для построения статистик.

Реквизиты шапки справочника:

  • Наименование. Наименование настройки рабочего стола статистик.
  • Количество диаграмм в строке. Указывается количество диаграмм статистик в одной строке на рабочем столе статистик.
  • Размер шрифта. Указывается размер шрифта подписей осей диаграмм статистик, по умолчанию заполняется значением 12.
  • Количество периодов для построения. Указанные данные используется для заполнения периода рабочего стола статистик по умолчанию.

  • Отображать только завершенный период Если признак установлен, то на диаграмме не будет отображаться значение незавершенного периода (если период «Неделя» - значения текущей недели и т.д.).

Табличная часть настроек:

  • Заголовок. Отображается над диаграммой статистики.
  • Статистика. Вид статистики из справочника "Виды статистик", которая будет строиться.
  • Отбор по детализации 1, Отбор по детализации 2, Отбор по детализации 3. Аналитики из справочника "Виды аналитики статистики", в разрезе которых будет строиться статистика.
  • Периодичность графика. Выбирается период детализации: день, неделя, месяц, квартал или год. Обозначаем одну точку на графике статистики.
  • Цвет графика. Цвет графика статистики
  • Тип и период квоты. Устанавливается нарастающая (накопительная) или обычная квота и период, в течение которого она дейтсвует.
  • Сдвиг периода и вид сдвига. Устанавливается количество периодов и период на который необходимо сдвинуть данные на графике. (Обычно применяется для сравнения одного и того же вида статистики, но за несколько переодов)
  • Минимальное значение/Максимальное значение. Задают масштаб графика статистики.
  • Легенда. Подпись графика статистики. Используется при построении нескольких графиков статистики на одной даграмме. Для того, чтобы построить несколько графиков статистики на одной диаграмме, необходимо в табличной части указать одинаковые заголовки диаграммы и детализацию для соответствующих строк.
