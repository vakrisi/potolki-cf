Справочник «Планы действий»

Справочник «Планы действий» предназначен для хранения информации о боевых планах сотрудников организации.

Реквизиты шапки справочника:

  • Наименование. Формируется автоматически на основании поста, периода и состояния.
  • Основание. Боевой план, на основании которого сделан текущий план. Если боевой план создан копированием существующего плана, но иерархическое представление не нужно, то поле основание необходимо очиститьОснование автоматически заполняется при создании боевого плана копирование существующего плана. При заполненном основании боевые планы буду отображаться с иерархией (удобно использовать, например, при детализации планов по дням/неделям и т.д.)
  • Пост. Указывается пост из справочника "Оргсхема", на который ставится план. Если при создании боевого плана был выделен пост, то значение поля «Пост» будет заполнено текущим постом. Если при создании боевого плана был выделен боевой план, то значение поля «Пост» будет заполнено постом из текущего боевого плана.
  • Вид статистики. Автоматически берется из настроек статистик поста, указанных на оргсхеме или выбирается вид статистики из справочника "Виды статистики" для плана.
  • Текущее значение статистики. Указывается текущее значение статистики (например, если период плана действий — неделя, то текущее значение статистики указывается за неделю до периода планирования).
  • Квота. Задается планируемое значение выбранной статистики за указанный период плана действий.
  • Предыдущая квота. Заполняется автоматически (при создании на основании существующего боевого плана или копировании существующего боевого плана) последним значением квоты для поста и вида статистики.
  • Состояние. Указывается текущее состояние статистики из справочника "Состояния".
  • План с ... по ... . Указывается период планирования.

 

Табличная часть заполняется планом действий на период планирования.

По кнопке «Печать» можно распечатать боевой план.
